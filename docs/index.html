Gestão solidária de doações, estoque e entregas

O Elos conecta doadores, recursos e famílias em um fluxo rastreável: cada doação validada entra no estoque, cada entrega confirmada gera uma saída e cada movimento fica registrado no histórico.

O problema

Doação sem rastreabilidade vira estoque sem confiança.

Iniciativas sociais costumam controlar doações em planilhas e mensagens. Quando o volume cresce, fica difícil saber o que entrou, o que já foi entregue e qual saldo está realmente disponível.

O Elos foi desenhado para tornar esse fluxo explícito: o saldo não é digitado, ele é derivado dos movimentos. Validação, entrega, cancelamento e ajuste passam por regras verificáveis e deixam histórico.

Fluxo ponta a ponta

Da doação à entrega, com saldo auditável.

O caminho principal da v1 foi implementado e testado de ponta a ponta.

  1. 01

    Cadastrar recurso

    Nome, tipo, unidade, categoria e estoque mínimo.

  2. 02

    Registrar doação

    Doador, data, responsável e um ou mais itens.

  3. 03

    Validar doação

    O status muda para disponível e o estoque recebe a entrada.

  4. 04

    Registrar entrega

    Família, itens e conferência de saldo antes da confirmação.

  5. 05

    Confirmar entrega

    A saída é registrada e o saldo é atualizado na mesma transação.

  6. 06

    Auditar histórico

    Cada evento guarda ação, data e responsável.

Arquitetura

Simples de rodar, difícil de quebrar.

A aplicação usa apenas recursos nativos do Node.js. Não há build de frontend, banco externo ou dependência instalada. A interface é renderizada no servidor e o banco SQLite é criado automaticamente.

Importante: o sistema completo é uma aplicação Node.js. O GitHub Pages publica esta vitrine estática, mas não executa o backend. Para usar o sistema, rode node server.js localmente ou publique em um serviço que execute Node.js.

Executar localmente

Três comandos e o sistema está no ar.

Requisito: Node.js 22.5 ou superior. Não é necessário instalar dependências.

  1. 1 Crie o banco de demonstração com dados fictícios.
  2. 2 Inicie o servidor e abra o endereço local.
  3. 3 Rode a suíte de testes quando quiser.
# banco de demonstração
node scripts/seed.js

# servidor em http://127.0.0.1:3000
node server.js

# validação automatizada
node --test
